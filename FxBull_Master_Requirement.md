# FxBull Trading Journal - Master Requirement

## Project Overview

FxBull is a professional AI powered trading journal and analytics
platform.

The design should follow the provided reference screenshots: - Dark
premium SaaS interface - Trading dashboard style - Modern fintech UI

## Pages Required

### 1. Dashboard

Features: - Trader profile - Today's P&L - Balance - Total P&L - Best
Day - Trading Streak - Win Rate - Total Trades - Biggest Win - Average
Win - Average Loss - Recent Trades - Sync Trades button

### 2. Analytics

Sections: - Performance - Reports - Strategies - Trade Replay - Share
Cards

Performance: - Win Rate - Profit Factor - Expectancy - Total P&L - P&L
charts - Win/Loss analysis - Asset performance - Time based
performance - Drawdown analysis - Streak tracking - Symbol performance -
Trading heatmap

### 3. Trade History

Required: - Trade list - Search - Filters - Open/Closed trades - Sync
broker trades

Trade fields: - Date - Symbol - Buy/Sell - Entry price - Exit price -
Lot size - Stop loss - Take profit - Strategy - Profit/Loss - Notes

### 4. Trading Journal

Features: - Calendar view - Day view - New journal entry

Journal fields: - Date - Market condition - Trade reason - Emotion -
Mistakes - Lessons learned - Screenshot upload

Calendar status: - Green = Profit day - Red = Loss day - Purple =
Journal added

### 5. Strategies

Features: - Create strategy - Save rules - Track performance

Strategy data: - Name - Description - Market - Timeframe - Entry rules -
Exit rules - Risk management

### 6. Trade Replay

Features: - Select previous trade - Chart replay - Entry marker - Exit
marker - SL/TP display - Candle playback

### 7. Share Cards

Features: - Daily report card - Monthly report card - Yearly report
card - Generate image - Download/share

### 8. FxBull AI

AI features: - Trade analysis - Performance review - Mistake detection -
Strategy improvement suggestions - Psychology analysis

### 9. Broker Hub

Features: - Connect broker - MT5 support - Account sync - Balance -
Equity - Unrealized P&L - Broker management

### 10. Settings

Sections: - Profile - Subscription - Notifications

Profile: - Name - Email - Avatar - Timezone - Currency

## UI Requirements

-   Responsive desktop and mobile
-   Dark theme
-   Premium cards
-   Smooth animations
-   Professional trading platform look

## Recommended Stack

Frontend: - React - TypeScript - Tailwind CSS

Backend: - Node.js/Laravel API

Database: - PostgreSQL

Charts: - TradingView Lightweight Charts - Recharts

## Development Rule

No feature from this requirement should be removed. The final product
must match the provided reference screenshots in structure and user
experience.
